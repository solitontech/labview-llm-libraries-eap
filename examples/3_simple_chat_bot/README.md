# About This Example
This example demonstrates how to use the LabVIEW LLM libraries to build a simple chat bot.

# Usage Instructions
1. **Enter OpenAI Key:** In the block diagram of `simple_chat_bot.vi`, enter your OpenAI API key.
4. **Ensure Node.js Installation:** Confirm that Node.js (version 18.20.4 or higher) is installed on your system. This example temporarily uses Node.js to host services for displaying conversations on the UI. Future versions will remove this dependency.
5. **Run the VI:** Execute `simple_chat_bot.vi` to start the chat application. You can ask any question and the model will response.
